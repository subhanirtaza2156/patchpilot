# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security of developer systems and credentials is our top priority. PatchPilot is designed to run locally without exposing user code or API keys to third parties.

If you discover a potential security vulnerability in PatchPilot:

1. **Do not open a public GitHub issue.**
2. Send an email to `subhanirtaza2156@users.noreply.github.com` with the subject: `[SECURITY] Potential vulnerability in PatchPilot`.
3. Include detailed steps to reproduce the issue, potential impact, and suggested remediations if known.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch release.
